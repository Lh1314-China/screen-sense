# 发布步骤（照着做就行）

从零到发出去，大约 30 分钟。**下面所有命令都在项目根目录执行。**

---

## 第 0 步：先确认成品状态

```powershell
powershell -ExecutionPolicy Bypass -File tests\test_lib.ps1
powershell -ExecutionPolicy Bypass -File tests\test_privacy.ps1
```

两条都要 `RESULT: all passed`，否则别发。

---

## 第 1 步：打发布包

```powershell
$ver = "0.2.0"
$zip = "screen-sense-$ver.zip"
Compress-Archive -Path .\screen-sense\* -DestinationPath $zip -Force
$hash = (Get-FileHash $zip -Algorithm SHA256).Hash
"$zip  $hash"
```

把输出的哈希记下来，Release 说明里要用。

---

## 第 2 步：建 GitHub 仓库

**网页版（最省事）**

1. 打开 <https://github.com/new>
2. 仓库名：`screen-sense`
3. 可见性：Public
4. 初始化：**不要**勾 README / .gitignore / license（我们本地已经有了）
5. 点 Create

**命令行版**

```powershell
# 需要先装 git，并登录过 GitHub
git init
git add .
git commit -m "feat: screen-sense v0.2.0 - 免截屏的屏幕感知"
git branch -M main
git remote add origin https://github.com/<你的用户名>/screen-sense.git
git push -u origin main
```

---

## 第 3 步：打标签 + 发 Release

**网页版**

1. 仓库页右侧 **Releases** → **Create a new release**
2. Tag：`v0.2.0`，Target：`main`
3. 标题：`v0.2.0 · 免截屏的屏幕感知`
4. 说明：复制下面「Release 说明模板」
5. 附件：把第 1 步的 zip 拖进去
6. Publish release

**命令行版**

```powershell
git tag v0.2.0
git push origin v0.2.0
# 需要先装 gh 并 gh auth login
gh release create v0.2.0 $zip --title "v0.2.0 · 免截屏的屏幕感知" --notes-file RELEASE.md
```

---

## 第 4 步：Release 说明模板

```markdown
## screen-sense v0.2.0 · 不截屏的屏幕感知

让 AI 知道「你在做什么」，而不是把每一帧都截图发上去。

- 单次感知 **10–40 ms / 约 140 token**
- 同屏截图要 **1843 token** —— 省 **92%**
- 默认**根本不截屏**，只有明确要求才升级成区域截图

### 装

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

### 这一版

- UIA 摘要 + 四级 token 预算裁剪（141 / 55 / 16）
- 增量事件流，静默期零开销
- 按需截图，落盘只留 20 张
- 密码框 / 密码管理器屏蔽
- 端口被占自动回退，不和别的插件抢

### 它不是什么

不是截图的替代品，是「导航层」：知道你在哪、点的是什么；
要看页面内容还是得截图。10 轮对话用「摘要 + 偶尔截一次」，省 81%。

SHA256: `<粘贴第 1 步的哈希>`
```

---

## 第 5 步：国内镜像（可选但建议）

**Gitee**：登录 <https://gitee.com> → 新建仓库 → 导入 GitHub 仓库，或同样 `git push` 到 gitee 的地址。

**蓝奏云 / 网盘**：只传 zip，不传源码；标题写清楚版本号。

---

## 第 6 步：装进 DSH

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

会把 `SKILL.md` 装到 `C:\Users\<你>\.dsh\skills\dsh-screen-sense\`，DSH 下次加载技能时就能看到。

验证：

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -Status
python query.py digest
```

---

## 第 7 步：软著登记（和发布并行，不用等）

1. 打开 <https://www.ccopyright.com.cn>，注册账号
2. 选「软件著作权登记」→ 在线填报
3. 软件全称：`screen-sense 屏幕感知软件`，版本 `V1.0`（注意：这里写 V1.0 更稳妥，不要写 0.2.0）
4. 材料：
   - 源程序：把 `daemon.ps1` `lib.ps1` `cdp.ps1` `query.py` `install.ps1` 合成一个 PDF，**前 30 页 + 后 30 页**
   - 文档：README + 兼容说明，合成 PDF
   - 身份证明
5. 提交后等 30–60 个工作日

**注意**：登记用的是**某个冻结版本**的源码，所以建议**先发 GitHub 再登记**，用 tag 对应的代码，别边改边交。

---

## 第 8 步：宣传文案（B站 / 群里）

> **给 AI 装一只「不看截图的眼睛」**
>
> 每次让 AI 看屏幕，它都要截一张图：1800 token，还慢。
> 这个小工具不截屏，只读系统的窗口信息：你现在在哪个程序、标题是什么、点在哪个按钮上——**140 token，几十毫秒**。
> 需要看内容时才截一张，默认永远不截。
> 单文件，PowerShell 写的，不用装依赖。MIT 开源。
